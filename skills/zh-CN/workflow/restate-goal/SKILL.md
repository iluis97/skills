# 复述目标

调用后暂停执行，先用自己的话复述两点：用户要达到的目标、当前要解决的问题。等待用户确认或纠正，确认后再继续。

## 复述什么

- **目标**：用户想要的最终结果，而不是他提到的动作或方案。
- **问题**：当前阻碍、痛点，或触发这次请求的原因。
- 只复述到能判断“理解是否一致”的程度，不重述全部细节，也不展开实现方案。

## 怎么复述

- 基于当前对话、已有产物和用户提供的材料；用能体现自己理解的说法，不把原文改写一遍当复述。
- 区分“用户明确说的”和“我推断的”：推断部分标明依据，依据不足时列为待确认。
- 存在多种合理解读、缺少关键信息，或目标与所提方案明显不匹配时，指出关键歧义并请用户选择，不自行选定一种继续。
- 不把行业惯例或通用最佳实践当作用户目标，也不复述超出用户表达范围的猜测。

## 输出

```text
目标：<用户想达到的结果>
问题：<当前要解决的问题>
依据：<来自对话或材料的明确信息>
待确认：<推断部分、歧义或缺失信息；没有则写“无”>
```

## 边界

- 复述用于对齐理解，不替代用户对关键取舍的决定；未确认前不开始实现。
- 用户已明确目标并要求直接执行时，按其要求推进，不因本技能延迟已授权的工作。
