# 容器环境排查

仅用于涉及 Docker 的场景。按主技能固定的排查对象、时间范围和证据纪律执行。

- 容器定位：按容器名称、Compose 服务及项目标签定位，固定容器身份；同一服务有多个实例时保留实例区分。容器内执行命令前确认与目标进程的用户及权限一致。
- 实时状态与日志：对指定服务的容器使用 `docker logs --since/--until --timestamps` 读取固定时间窗；持续观察时使用 `--follow` 并设置观察时限，报告实际起止时间，不无限挂起。
- 历史日志：通过 `docker inspect` 核对挂载目标与宿主机来源，再按文件规则定位和读取；挂载目录较多时，以服务及挂载关系缩小候选范围，不直接扫描所有挂载目录。
- 缺口报告：挂载缺失、容器已删除且无法确认原挂载、权限不足或保留期不足时，说明已核验范围和缺口；不静默改用其他来源并声称覆盖目标范围。
- 需要完整日志纪律（时间窗、轮转、统计口径）时，提示用户显式调用 `log-analysis`。
