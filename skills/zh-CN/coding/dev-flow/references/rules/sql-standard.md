# SQL 规范

## S1 参数化

所有 SQL 使用参数化查询。禁止字符串拼接 SQL，包括 ORM raw query。动态表名、列名和排序字段必须白名单校验。

## S2 索引

- WHERE、JOIN、ORDER BY 字段应有索引支持。
- 联合索引遵循最左前缀。
- 不在索引字段上套函数。
- 新增索引需评估写入性能。

## S3 查询

- 禁止 `SELECT *`。
- 禁止循环内查询，改为批量查询。
- 大表查询必须有 LIMIT 或流式读取。
- 禁止前缀模糊 `LIKE '%keyword'`。
- JOIN 数量按项目规范控制。

## S4 分页

- 分页必须限制 page size。
- 深翻页改为游标分页。
- 游标分页使用稳定排序字段。

## S5 事务

- 事务范围最小化。
- 不在事务内做 RPC 或 HTTP 调用。
- 必须有回滚处理。
- 避免无依据的事务嵌套。

## S6 DDL

- 新表必须有主键。
- 按项目约定提供创建和更新时间。
- 字段约束、默认值、长度和大字段拆分遵循项目规范。

## S7 数据安全

- 敏感字段加密存储，日志脱敏。
- 批量 UPDATE/DELETE 必须有 WHERE 条件。
- 软删除和审计字段遵循项目契约。
