# 异常与日志

## 异常与日志

- 按项目已有异常契约报告失败，复用校验工具、业务异常和错误码。
- 捕获异常用于有依据的恢复、补充排查上下文或转换异常语义；其他情况交给统一异常机制，转换时保留必要原因链。
- 契约明确允许的空结果、默认值、恢复、降级和跳过保留其语义；恢复或降级失败时继续按约定传播失败。
- 沿用项目日志框架和级别，参数化记录关键变化、外部失败及排查上下文；序列化或较重计算前检查日志级别。
- 同一业务流程使用统一、可检索的业务关键字前缀，保留关键业务标识和处理步骤或结果。
- 当前层负责记录异常时保留堆栈，明确沿调用链的记录职责。

### 禁止项

- **失败伪装成功**：禁止将真实失败转换为空集合、空值、默认对象、零值或成功返回，或跳过异常数据后继续执行；契约明确允许的除外。
- **吞掉与宽泛捕获**：禁止空捕获、捕获后既未恢复也未按契约传播失败便继续正常流程，或用宽泛异常捕获隐藏真实错误；边界统一转换或恢复确需宽泛捕获时，保留失败语义。
- **无效高频日志**：禁止增加缺少排查价值的高频过程日志。
- **敏感信息泄露**：禁止向调用方暴露堆栈或底层敏感细节，禁止在日志中输出凭据、令牌或完整敏感对象。
