# 数据、异常与资源管理

修改数据访问、事务、缓存、异常、日志、消息、外部调用、并发、资源生命周期或性能逻辑时，按涉及的主题阅读；未涉及的主题无需展开。

## 异常与日志

- 按项目已有异常契约报告失败，复用校验工具、业务异常和错误码，错误消息说明具体业务原因。
- 捕获异常用于有依据的恢复、补充排查上下文或转换异常语义；其他情况交给统一异常机制，转换时保留必要原因链。
- 契约明确允许的空结果、默认值、恢复、降级和跳过保留其语义；恢复或降级失败时继续按约定传播失败。
- 沿用项目日志框架和级别，参数化记录关键变化、外部失败及排查上下文；序列化或较重计算前检查日志级别。
- 同一业务流程使用统一、可检索的业务关键字前缀，保留关键业务标识和处理步骤或结果。
- 当前层负责记录异常时保留堆栈，明确沿调用链的记录职责。

### 禁止项

- **失败伪装成功**：禁止将真实失败转换为空集合、空值、默认对象、零值或成功返回；契约明确允许的空结果、恢复和降级除外。
- **无依据跳过**：禁止跳过异常数据后继续执行，除非业务或接口契约明确允许该处理。
- **吞掉异常**：禁止空捕获，或捕获后既未恢复，也未按契约传播失败，仅记录日志便继续正常流程。
- **宽泛捕获掩错**：禁止使用宽泛异常捕获隐藏真实错误；边界统一转换或恢复确需宽泛捕获时，保留失败语义。
- **重复记录异常**：禁止沿调用链反复记录同一个异常。
- **无效高频日志**：禁止增加缺少排查价值的高频过程日志。
- **错误详情泄露**：禁止向调用方暴露堆栈或底层敏感细节。
- **日志泄密**：禁止在日志中输出凭据、令牌或完整敏感对象。

## 数据访问与批量操作

- 复用项目已有数据访问组件和服务查询，查询条件符合业务和权限范围。
- 查询考虑次数、索引使用和实际数据范围，适合批量处理的访问优先批量完成。
- 批量操作明确批次大小、事务范围和部分失败处理。
- 更新和删除明确操作条件及范围，保留必要的返回值检查、并发控制和重复执行语义。

### 禁止项

- **循环逐条访问**：禁止在循环中逐条执行可批量完成的数据库或外部调用。
- **破坏业务原子性**：禁止在批量改造中改变原有业务原子性要求。

## 事务与外部副作用

- 按业务原子性划定事务边界，需要多个写操作一致时使用项目已有事务机制。
- 遵守框架事务管理、传播和回滚规则，确认调用方式及异常类型能触发预期行为。
- 明确外部调用、缓存修改和消息发送与数据库提交的先后关系及失败补偿。
- 复用已有一致性机制，按业务原子性与调用耗时安排外部调用的位置。

### 禁止项

- **误判回滚范围**：禁止将本地事务回滚视为外部调用、缓存或消息副作用已自动撤销。
- **长事务中的无关调用**：禁止将业务原子性不需要的外部调用放入长事务。
- **过度建设补偿框架**：禁止在缺少实际复用或一致性需求时，新建通用事务或补偿框架。

## 缓存一致性

- 重复且可可靠失效的热点中间结果可以缓存，优先复用项目已有组件。
- 明确缓存键、生命周期、容量、写后失效及并发语义。
- 数据库写入后维护缓存时，优先复用提交后回调。
- 明确无事务场景和回调失败的处理方式；回调顺序本身不保证跨系统一致性，按业务需要保留既有重试、失效或补偿机制。

### 禁止项

- **缓存参数照搬**：禁止未经当前业务评估，直接采用其他业务的缓存容量或 TTL。
- **回滚后缓存残留**：禁止在数据库回滚后保留本次写入产生的缓存变化。
- **误信回调顺序**：禁止将提交后回调的执行顺序当成跨系统一致性保证。

## 并发与重复执行

- 并发实现同时考虑线程安全、业务状态、数据一致性和资源竞争。
- 检查状态可能在校验后变化的场景。
- 按项目约定使用条件更新、锁或其他已有并发机制。
- 涉及重试、消息重投或重复请求时，明确重复执行及副作用语义；仅在业务需要时沿用或补充幂等处理。

### 禁止项

- **依赖过期状态**：禁止在状态可能变化时，将此前读取或校验的结果当成后续写入的永久保证。
- **移除并发保障**：禁止将必要的并发和一致性检查当作重复判断删除。

## 资源生命周期

- 明确资源所有权、依赖方向、创建与释放责任，沿用项目生命周期管理方式。
- 正常结束、异常、提前返回及取消时，均保证本层拥有的资源得到正确释放。
- 借用或由容器管理的资源遵守其生命周期。

### 禁止项

- **越权关闭资源**：禁止擅自关闭借用或由容器管理的共享资源。
- **资源泄漏**：禁止在异常、提前返回或取消路径中遗漏本层拥有资源的释放。

## 性能取舍

- 先识别实际瓶颈，优先减少重复计算、无效查询、不必要的数据转换及可批量处理的访问。
- 根据访问方式和数据规模选择数据结构；引入缓存、批量或并发时一并评估内存、事务及一致性代价。

### 禁止项

- **无依据优化**：禁止仅凭主观判断增加优化层次，或引入缺乏实际收益却增加复杂度的微优化。
- **虚报性能收益**：禁止声称未经验证的性能收益。
