# Java 编码规则

以下规则仅应用于 Java；Lombok、MyBatis-Plus 等规则仅在项目已使用对应依赖时生效。

## Lombok 与对象建模

- 用 Lombok 简化普通 Bean、请求/响应、配置对象与枚举；按需选择 getter、setter、构造器、builder 和日志注解。
- 可变 Bean 沿用 `@Data` 风格，只读对象仅开放读取；确认生成的 `equals`、`hashCode`、`toString`
  合适。涉及继承、实体关联或敏感字段时显式控制，避免递归或泄露。
- 构造器注解满足框架实例化要求，`@Builder` 按构建可读性需要使用。
- 注入方式沿用目标模块；无约定且使用 Lombok 时可用 `@RequiredArgsConstructor` 配合 `private final`。
- 简单稳定的响应转换可用 `static of(...)` 显式逐字段映射；已有统一转换组件时优先沿用。
- 复用实体公共基类字段与表映射约定，仅在父类字段应参与相等性判断时使用 `@EqualsAndHashCode(callSuper = true)`。

### 禁止项

- **构建器替代校验**：禁止使用 `@Builder` 代替必填字段校验。
- **注解一律套用**：禁止默认给所有类添加 `@Builder`，或不判断相等性语义就统一添加 `@EqualsAndHashCode(callSuper = true)`。
- **批量改写注入**：禁止仅为统一注入形式而批量替换存量代码。
- **忽略生成方法风险**：禁止在涉及继承、实体关联或敏感字段时，忽略生成方法造成的递归或泄露风险。

## 枚举

- 枚举的编码与描述存入由构造器初始化的字段，对外使用显式定义的稳定编码。
- 使用 Lombok 时，可用 `@Getter`、`@AllArgsConstructor` 与 `private final` 属性；命名、编码类型、字典注解沿用项目。

### 禁止项

- **序号作为对外编码**：禁止使用 `ordinal()` 作为对外编码。
- **强制枚举形式**：禁止脱离项目约定，强制使用 `Enum` 后缀、`Integer` 编码类型或构造器注解。

## 集合、数值与数据访问

- 简单转换可用 Stream，复杂分支或副作用优先用循环；简单可空转换可用 `Optional`，复用的转换可传入 `Function`。
- 按业务使用 `BigDecimal`，数值比较用 `compareTo`，需同时比较数值与标度才用 `equals`。
- 业务允许重复键时，为 `Collectors.toMap` 提供实现业务冲突策略的合并函数；未提供合并函数时，重复键会抛出异常。
- 已使用 MyBatis-Plus 时，可用 `LambdaQueryWrapper` 和 getter 方法引用。
- 使用代理式事务时，确认调用经过代理，且配置的回滚规则覆盖预期异常类型。

### 禁止项

- **无意义的 API 包装**：禁止引入没有独立职责或可读性收益的调用层次，仅用于套用 Stream、`Optional` 或 `Function` 写法。

## Javadoc

- 本次新增或契约、业务语义发生变化的手写类、接口、方法与构造器须提供或更新有意义的中文 Javadoc，私有方法同样适用；字段、常量和枚举项按入口中的业务注释规则处理。
- 类与接口说明职责，方法与构造器说明行为；实际参数使用 `@param` 描述含义及必要约束，有返回值时使用 `@return` 说明结果语义，调用方需要了解的异常使用 `@throws` 说明触发条件。
- 涉及调用前提、副作用、边界或失败语义时，补充影响使用和维护的必要说明；按实际契约描述，不为不存在的参数、返回值或异常补凑标签。
- 重写方法在项目允许且继承文档完整、准确时可以复用继承文档；实现特有的约束、副作用或失败行为须补充，不能仅凭 `@Override` 认定文档完整。
- 核对本次修改涉及的文档是否仍与实现一致，不批量补齐未受影响的历史声明；生成代码及工具生成的成员按项目约定处理，不为补文档改写生成机制。
- 类、方法、构造器与字段的 Javadoc 放在声明整个注解块上方；无注解时直接放在声明上方。

### 禁止项

- **Javadoc 位置错误**：禁止将 Javadoc 插在注解之间或注解与声明之间。
