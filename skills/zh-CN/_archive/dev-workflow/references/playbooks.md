# 任务类型方法

本文件补充缺陷修复、重构、功能、只读调查和性能这五类任务的具体做法。开始、交接、分流、等待和完成的条件仍以 [progression.md](progression.md) 为权威来源；本文件不新增门禁，也不替代核验与记录规则。

按任务的主要目的选择一类；同一任务跨多类时按依赖顺序组合，例如先只读调查，再缺陷修复，最后重构。类型判断有歧义时说明采用的类型和依据。

## 缺陷修复

适用于已有可观察的错误行为，包括回归、异常输出和状态不一致。

1. **在匹配的真实面复现**：记录输入、环境、频率和实际结果。不能直接复现时收紧条件、合成触发或增加观测，直到问题可见；不先猜原因。用户提供的复现步骤只作线索，仍须自己确认。
2. **归因**：列候选假设，用运行证据逐个排除；需要时加日志、trace、断点或临时观测读取实际状态。不要只读代码就确定原因。
3. **判断状态是否合法**：触发问题的状态本身合法时，在代码出错的位置处理；不该存在的状态则继续追到产生它的位置，不用兜底、重试或吞异常掩盖。
4. **最小修复**：只改证据支持的缺陷；“可能有用”的防御性改动先当作假设，没有证据不进入交付。
5. **同一真实面复验**：原复现通过才算修复；单元测试只能证明分支行为，不能单独证明缺陷消失。无法在真实面复验时说明限制，不写成通过。
6. **顺序**：能拆出廉价失败用例时，失败用例或可复现证据的提交排在修复之前；代价过高时说明取舍。

交付：原现象、根因、修复、同面复验证据、未覆盖部分。

## 重构

适用于外部行为不变，只调整结构、命名、分层或数据形状。

1. **钉住行为契约**：改动结构前，用 characterization test（行为特征测试）、快照、录制回放或等价性 harness（新旧输出对比装置）捕获当前行为；没有覆盖时先补 pin（钉住当前行为的检查）。类型检查、lint 和“能编译”不是行为 pin。
2. **确定目标形状**：说明模块布局、核心类型和调用关系应是什么样；目标不清晰时先调查，不边改边定。
3. **先减后加**：删除死代码、无调用包装、失效校验和孤儿引用，再引入新形状；不为过渡保留平行旧路径。
4. **小步移动**：每次只做一个行为保持的调整，pin 通过后再继续。内部 API 变更时同批迁移全部调用方并删除旧路径，除非存在外部兼容要求。
5. **等价性验证**：在真实产物上对比新旧输出、回放基线或运行冒烟路径；“能编译”和单元测试全绿不足以证明行为不变。
6. **判断收益**：读者定位问题和理解状态的负担应下降；没有下降就回退，不为了“更整齐”保留改动。

交付：改动的结构、使用的 pin、等价性证据、读者负担变化、回退的内容。

## 功能

适用于新增或改变用户可观察的行为。

1. **先定数据形状**：明确核心类型、状态、所有权和边界；跨函数或模块时先定接口、调用方式和错误契约，再写实现。
2. **复用优先**：先找项目已有类型、组件、机制和约定；说明本次不做什么，防止范围自行扩大。
3. **实现**：在授权范围内完成，保持既有契约；新增行为覆盖正常、边界和失败路径，必要时同步测试与文档。
4. **验证**：走真实用户路径或项目已有的可运行入口；不能只靠单元测试、“能运行”或结构齐全。涉及交互、观感或体验时，按 [verification.md](verification.md) 的感知目标处理。
5. **按可验证单元交付**：每个单元结束在可检查状态，通过后再进入下一个；相关改动不跨单元混在一起。

交付：实际行为、关键取舍、验证证据、未覆盖部分。

## 只读调查

适用于回答“怎么工作”“为什么这样设计”“是否安全”“会影响什么”，不修改代码。

1. **固定问题和输出**：明确要回答的问题、范围和期望结论形式；保持只读。
2. **追事实**：从入口追调用链、数据流、状态变化和配置来源；动机问题查提交、PR、文档和讨论记录，区分记录中的事实与自己的推断。
3. **结论带定位**：文件与行、命令与输出、提交或文档位置；说明未确认部分和证据缺口。
4. **不顺手改**：调查转为修改时交回负责人，按缺陷修复、功能或重构重新组织，不在调查过程中直接落代码。

交付：结论、关键流程或概念、证据位置、风险与未确认项。

## 性能

适用于有可测量指标的慢、吞吐低或资源占用高。

1. **先写决策**：明确指标、目标值和什么结果会改变当前做法；记录基线、运行次数和波动范围。
2. **测量并归因**：从 profile、trace、计数器或实际运行确认限制因素，回答“为什么不能翻倍”；只读代码猜瓶颈不算证据。
3. **排除测错对象**：错误、缓存或跳过的工作、未执行的代码、未调优的一侧、噪声、过小的部分，逐项排除。
4. **最小改动**：只改证据支持的瓶颈，一次一个变量，前后在相同负载和环境对比。
5. **复验**：同一指标和条件下对比基线与结果；波动大于效应时不宣称提升或回归，保留数据和限制因素。

交付：指标定义、基线、限制因素、改动、前后数据与波动、未验证部分。
