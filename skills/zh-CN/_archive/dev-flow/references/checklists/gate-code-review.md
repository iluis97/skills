# CODE-REVIEW 门禁

## 必须通过

### 前置校验

- [ ] `workflow.py validate --stage TASK-03` 已通过
- [ ] `03-code/stage-result.json` 的 `files_changed` 全部位于执行计划白名单并集
- [ ] 实际变更文件全部位于执行计划所有 PT 的 `files_whitelist` 并集内
- [ ] 所有 PT 的 acceptance 项均有 PASS 结果和可核对证据
- [ ] HTTP API 新增、修改或删除时，`03-code/api-docs.md` 存在且非空
- [ ] API 文档中的路由、方法、字段、枚举和错误响应与实际代码一致

### 安全

- [ ] SQL 使用参数化查询
- [ ] 无硬编码密码、密钥、Token 或敏感地址
- [ ] 用户输入经过契约要求的校验
- [ ] 权限和越权边界正确
- [ ] 日志和错误消息不泄漏敏感信息

### 数据与并发

- [ ] 事务范围、回滚和幂等性符合契约
- [ ] 数据迁移、删除和更新有明确边界
- [ ] 共享资源、并发和锁使用正确

### 性能

- [ ] 无明显 N+1 查询
- [ ] 大数据量查询有分页、LIMIT 或流式处理
- [ ] 新增或修改的 WHERE、JOIN、ORDER BY 有合理索引

### 质量

- [ ] 实现与技术方案一致，无无依据的抽象或依赖
- [ ] 无未处理错误或吞错
- [ ] 关键业务变化有足够日志和可诊断信息
- [ ] 变更报告中的验证结果真实且与风险相称

## 建议检查

- [ ] 函数职责完整，拆分有独立语义
- [ ] 命名自解释，无魔法值
- [ ] 无死代码和注释掉的代码块
- [ ] 无重复实现已有能力
- [ ] 注释解释原因而非重复代码

## 判定

- PASSED：必须通过项全部满足，无 P0 和 P1。
- FAILED：任一必须通过项不满足，或存在任意 P0/P1。
