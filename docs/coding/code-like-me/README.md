# code-like-me

## 做什么

在实现、修改或重构代码时应用个人编码偏好：职责清晰、主流程易读、组合复用，以及有契约依据的校验与错误处理。明确任务要求和项目约定优先。

## 什么时候使用

通过 `$code-like-me` 显式调用，并提供需要完成的任务或已有讨论上下文。

```text
$code-like-me
实现订单查询接口，沿用当前模块的分页和异常契约。
```

通用规则位于英文入口；处理 Java 时，Agent 在实施前读取包内 `references/java.md`。其他语言不需要加载 Java 专属规则。阅读时可查看 [Java 中文补充规则](references/java.zh-CN.md)。

## 常见问题

- **会统一整个项目的风格吗？** 只修改任务所需范围，优先沿用局部约定，不批量格式化或升级依赖。
- **会强制引入 Lombok 或 MyBatis-Plus 吗？** 这些规则仅在项目已使用相应依赖时适用。
- **只想讨论方案可以调用吗？** 可以。用户只要求分析时，技能保持该范围。

## 如何判断执行符合预期

- 方法职责完整，抽取有实际意义，主流程按业务步骤展开。
- 业务固定值表达含义，复用已有组件，不新增无需求依据的抽象或兜底。
- 接口、权限、事务与并发保障得到保留，验证与改动影响相称。
