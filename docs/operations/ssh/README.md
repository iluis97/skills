# ssh

## 做什么

复用已有认证，对指定服务器执行有超时限制的 SSH 访问验证。需要公钥配置时，提供由用户自行执行的原生命令。

## 什么时候使用

通过 `$ssh` 显式调用，提供目标 IP 和登录用户名；端口默认 22，也可指定密钥路径。

```text
$ssh
验证 deploy@192.0.2.10 的 SSH 连接，端口 2222。
```

Agent 先确认目标和运行环境，再读取包内 `references/commands.md` 中对应 Shell 的部分。已要求后续操作时，验证成功后继续已授权工作。阅读时可查看 [SSH 中文命令参考](references/commands.zh-CN.md)。

## 常见问题

- **只给 IP 会默认 root 吗？** 不会，先询问该目标的用户名；同一目标已经明确确认过则复用。
- **验证后连接会一直开着吗？** 不会，使用短暂会话。后续命令需要复用参数重新建立会话。
- **认证失败会自动改配置吗？** 不会。根据错误提供下一步；生成密钥和安装公钥由用户在终端执行。
- **主机密钥变化怎么办？** 停止并说明不匹配，不自动删除记录或关闭校验。

## 如何判断执行符合预期

- 始终使用当前目标和已确认账号，命令适配本地及远端 Shell。
- 只有退出码为零且输出包含验证标记时才报告成功。
- 不读取或输出私钥、密码，待配置时明确报告尚未连接成功。
