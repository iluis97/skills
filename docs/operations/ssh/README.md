# ssh

## 做什么

让用户连上指定的服务器：验证并建立 SSH 连接，连不上时按错误归因并指导用户完成连接；连接成功后，在用户要求范围内直接执行远程 SSH 操作。当前提供[中文技能入口](../../../skills/zh-CN/operations/ssh/SKILL.md)。

## 什么时候使用

通过 `$ssh` 显式调用，提供目标 IP 和登录用户名；端口默认 22，也可指定密钥路径。

```text
$ssh
连接 deploy@192.0.2.10，看下磁盘占用；端口 2222。
```

Agent 先确认目标与运行环境，再读取包内 `references/commands.md` 中对应 Shell 的部分；公钥安装等命令模板也在该参考中，由用户在自己的终端执行。

## 常见问题

- **只给 IP 会默认 root 吗？** 不会，先询问该目标的用户名；同一目标已确认过则复用。
- **连接成功后会一直开着吗？** 不会，验证用短暂会话；后续操作按需重新建立会话。
- **什么操作会先确认？** 只读查看类直接执行；写文件、改配置、重启服务、清理数据等变更类先列命令征得确认。
- **认证失败会自动改配置吗？** 不会。按错误给出下一步，密钥生成与公钥安装由用户在终端执行。
- **主机密钥变化怎么办？** 停止并说明不匹配，不自动删除记录或关闭校验。

## 如何判断执行符合预期

- 始终使用当前目标和已确认账号，命令适配本地及远端 Shell。
- 只有退出码为零且输出包含验证标记时才报告连接成功。
- 只读操作直接完成，变更操作有确认记录，不读取或输出私钥、密码。

## 专属维护要求

- 技能保持“连接 + 远程操作”的目标导向结构，远程操作只写原则，不追加命令清单或穷举式禁令。
- 环境识别、连接与公钥安装的具体命令模板维护在包内 `references/commands.md`，按需读取；调整定位或边界时同步技能入口与本说明。
