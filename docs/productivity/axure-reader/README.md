# axure-reader

## 做什么

读取一个或一批 Axure、Axhub 原型链接，逐链接提取页面内容、批注与交互，并分别整理需求；用于原型分析、需求总结或字段及交互梳理。当前提供[中文技能入口](../../../skills/zh-CN/productivity/axure-reader/SKILL.md)。

## 什么时候使用

通过 `$axure-reader` 显式调用，直接给出一个或多个完整原型链接：

```text
$axure-reader https://example.axshare.com/abc
```

每个链接是独立分析对象，按输入顺序分别定位、提取和整理；某个链接失败不妨碍其他链接。默认只分析链接所指页面，需要全项目时明确说明。

## 常见问题

- **读取失败或内容不完整怎么办？** 脚本采集成功不代表目标匹配；查看 `references/troubleshooting.md` 处理登录、权限、页面不匹配等问题，无法读取的部分会如实报告。
- **静态页面文字就是全部交互吗？** 不是；必要时会用浏览器检查下拉、动态面板等状态，静态文字不等于完整交互。
- **依赖需要安装吗？** 脚本不自动安装依赖；缺少 Playwright 时按 `references/troubleshooting.md` 处理。

## 如何判断执行符合预期

- 每个链接独立输出页面名称、功能需求、字段及校验、交互和业务规则、待确认问题。
- 区分原型明确内容、推测和未验证交互，保留冲突而不自行裁决。
- 实际读取范围如实说明，未扩大到未授权页面。

## 专属维护要求

- 官方提取器脚本和许可证来源见包内 `scripts/axhub/SOURCE.md`，更新时保留来源说明。
- 调整读取或整理行为时同步更新技能入口与本说明，保持包内引用一致。
